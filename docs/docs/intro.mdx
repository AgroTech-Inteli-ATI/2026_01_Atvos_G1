# G01 — Atvos

Projeto de análise de dados agrícolas em parceria com a **Atvos**, desenvolvido no Módulo 10 do Inteli.

## Objetivo

Construir um pipeline de dados end-to-end para o inventário de talhões da Atvos, cobrindo ingestão, limpeza, análise exploratória e modelagem preditiva de produtividade (TCH).

## Sprint 1 — Pipeline de Dados

A Sprint 1 entregou a camada **Silver**: dados limpos, documentados e prontos para análise.

| Entregável | Status |
|------------|--------|
| Mapeamento das fontes | Feito |
| Script de ingestão Bronze | Feito |
| Regras de limpeza documentadas | Feito |
| Script de limpeza Silver | Feito |
| Dicionário de Dados Silver | Feito |

## Fontes de Dados

Três arquivos Excel fornecidos pela Atvos:

- **Inventário part 2** — 50.000 talhões, safras 2021/22
- **Inventário part 4** — 17.426 talhões, safras 2022/23
- **Correção de Talhões** — 23.599 pares de unificação/reforma

## Infraestrutura

O projeto roda localmente sem Google Cloud Platform. Alternativas:

| Original | Adotado |
|----------|---------|
| BigQuery | **DuckDB** — SQL in-process sobre Parquet |
| GCS | **Sistema de arquivos local** em `data/` |

## Sprint 2 — Motor de Regras Agronômicas

A Sprint 2 entregou a camada **Gold**: orientações agronômicas por talhão geradas por um motor de regras em Python.

| Entregável | Status |
|------------|--------|
| Motor de regras (5 processos) | Feito |
| Pipeline Silver → Gold | Feito |
| 471.982 registros Gold | Feito |
| Testes unitários | Feito |

## Sprint 3 — Backend e API REST

A Sprint 3 entregou o servidor HTTP que expõe os dados Gold para o frontend, sem dependências externas.

| Entregável | Status |
|------------|--------|
| Servidor HTTP (stdlib Python) | Feito |
| 6 endpoints JSON com filtros e paginação | Feito |
| Pré-cômputo de agregados em memória | Feito |
| 2 novos processos (insumos, dessecação) | Feito |

## Sprint 4 — Frontend e Integração

A Sprint 4 entregou a interface web completa com três telas e integração total com a API.

| Entregável | Status |
