# Frontend Atvos

Interface estatica do monitor agronomico, implementada com HTML, CSS e
JavaScript puro a partir do Figma do projeto.

## Executar

Na raiz do repositorio:

```powershell
python -m http.server 8000 --directory frontend
```

Depois acesse `http://localhost:8000`.

## Funcionalidades

- filtros por unidade, processo, insumo e status;
- busca por talhao e campos da orientacao;
- indicadores de acompanhamento;
- tabela responsiva;
- exportacao dos resultados filtrados em CSV;
- painel de filtros adaptado para dispositivos moveis.
